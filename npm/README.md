# disktracker

This package installs the disktracker binary for your platform and exposes it on PATH.

## Install

```bash
npm i -g disktracker
```

## Usage

```bash
disktracker scan
```

## Environment variables

- DISKTRACKER_VERSION: Override the release tag to install (e.g. v1.2.3).
- DISKTRACKER_REPO: Override the GitHub repo (default: pratham15541/disktracker).
